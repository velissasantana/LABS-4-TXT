<html>

3.HOST VIRTUAL EN PUERTO 80
sudo nano /etc/httpd/conf.d/holamundo.conf


Pegar:
<VirtualHost *:80>
DocumentRoot /var/www/holamundo
<Directory /var/www/holamundo>
Require all granted
</Directory>
</VirtualHost>

PRÁCTICA 3: SERVIDOR DE IMPRESIÓN CUPS (CENTOS STREAM 10)

Objetivo:
1. Instalar CUPS.
2. Instalar y configurar una impresora virtual PDF.
3. Agregar la impresora desde Windows mediante la IP del servidor.
4. Imprimir un documento de Word y comprobar el PDF generado.

PASO 1. INSTALAR Y CONFIGURAR CUPS EN CENTOS

sudo dnf install -y cups
sudo systemctl enable --now cups
sudo cupsctl --remote-admin --remote-any --share-printers
sudo firewall-cmd --permanent --add-service=ipp
sudo firewall-cmd --reload
sudo systemctl restart cups
ip -4 addr
sudo ss -lntp | grep 631

PASO 2. INTENTAR INSTALAR LA IMPRESORA PDF

sudo dnf install -y epel-release
sudo dnf install -y cups-pdf
sudo systemctl restart cups
lpstat -p -d

ATENCIÓN: cups-pdf puede no estar disponible en CentOS Stream 10. Si aparece "No match for argument: cups-pdf", detenerse: todavía NO hay impresora PDF instalada y se requiere un método compatible. No continuar suponiendo que existe.

PASO 3. ACCESO A CUPS DESDE WINDOWS

En Chrome abrir:
http://IP_DEL_SERVIDOR:631

Reemplazar IP_DEL_SERVIDOR por la IP de CentOS accesible desde Windows (preferiblemente la interfaz Host-only si ambas máquinas comparten VMnet1).

En CUPS: Administration > Manage Printers.
Verificar que la impresora PDF exista y esté compartida.

PASO 4. AGREGAR IMPRESORA EN WINDOWS

Configuración > Bluetooth y dispositivos > Impresoras y escáneres > Agregar dispositivo > Agregar manualmente.
Elegir la opción para agregar mediante dirección URL e introducir:
http://IP_DEL_SERVIDOR:631/printers/PDF

IMPORTANTE: "PDF" es un ejemplo. Usar el nombre real de la cola que aparece en CUPS. Windows puede requerir un controlador IPP compatible.

PASO 5. PRUEBA DESDE MICROSOFT WORD

1. Abrir Word en Windows.
2. Escribir: Prueba de impresión CUPS - Velissa.
3. Presionar Ctrl + P.
4. Elegir la impresora PDF de CentOS.
5. Pulsar Imprimir.

PASO 6. COMPROBAR EN CENTOS

lpstat -t
sudo find /var/spool/cups-pdf -type f -name '*.pdf'
